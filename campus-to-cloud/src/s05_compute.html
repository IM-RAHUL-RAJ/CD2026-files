#!/bin/bash
sudo yum update -y
# install and start Apache
sudo yum install -y httpd
sudo systemctl start httpd
sudo systemctl enable httpd
echo "<h1>Hello from $(hostname)</h1>" \
  > /var/www/html/index.html

Launch → wait a minute → open the public IP → your page is live.

The eight options and the user-data script come straight from PDF 04. The $(hostname) variant is from PDF 07: it prints which server answered, which is perfect for seeing a load balancer in action later.
