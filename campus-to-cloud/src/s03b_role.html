A role is a badge you clip onto a server

Click 1: you create the role once in IAM, with a permission policy (what it can do) and a trust policy (who can wear it: here, EC2). Then you attach it to the instance.

Click 2: AWS hands the server short-lived keys and renews them automatically. Behind the scenes they come from the instance metadata service on the host (169.254.169.254) and the AWS SDK picks them up for you.

Click 3: the app calls S3 and it works, with zero keys in the code. The old way, a secret key pasted into config, is how keys end up on GitHub, where bots find them within minutes.
