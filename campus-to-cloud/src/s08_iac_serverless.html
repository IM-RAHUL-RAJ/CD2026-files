Write what you want. AWS builds it.

Resources:
  WebSG:
    Type: AWS::EC2::SecurityGroup
  WebServer:
    Type: AWS::EC2::Instance
    Properties:
      InstanceType: t3.micro
      ImageId: ami-02db68a01488594c5
  Uploads:
    Type: AWS::S3::Bucket
  Database:
    Type: AWS::RDS::DBInstance

$ aws cloudformation create-stack --stack-name tw-uat --template-body file://infra.yaml

The EC2 resource and the create-stack command are from PDF 12. Each click adds a resource as CloudFormation creates it. Delete the stack and everything in it is removed cleanly too.

Five ideas behind infrastructure as code

Declarative

Say what you want. CloudFormation works out how and in what order.

Template

YAML or JSON, stored in Git, reviewed in pull requests.

Stacks

Everything from one template, managed together. StackSets: many accounts and Regions.

Managed state

AWS tracks what exists. No separate state file to lose.

Drift detection

Someone changed prod by hand? CloudFormation reports it.

CloudFormation itself is free. You pay only for what it creates.

All five points from PDF 12. Drift detection answers the "who changed prod at midnight" half of the struggle question.
